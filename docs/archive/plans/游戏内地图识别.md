# 游戏内地图识别

## 目标

在实体详情页和掉落详情页的“爆率显示”控制框中，紧邻“隐藏0爆率坐标”增加一个默认关闭的滑动开关。开启后懒加载本地截图识图模块，用户可以在模块指定区域按 `Ctrl+V` 粘贴 Windows `PrtScn` 截图，浏览器本地识别截图中与当前页面地图模块相同的地图图片，并以 50% 透明度绿色蒙版标出匹配边界，支持预览和导出标注后的图片。

## 范围与约束

- 识图仅在用户主动打开开关后加载，不改变 SSG 首屏、SEO、静态部署和默认 PWA 资源。
- 截图只在浏览器内处理，不请求上传接口，不申请 Windows 截图权限。
- 模板来源为当前页面已经展示的地图模块图片；必须覆盖当前页面滚动后能看到的全部模块，不能只使用当前视口中的懒加载图片。
- OpenCV.js 优先执行多尺度模板匹配；无可靠结果时使用 ORB 特征匹配兜底。
- 结果不叠加原始 WebP，只在截图对应区域绘制绿色透明蒙版。
- 实体详情页和掉落详情页共用识图组件、识别算法和导出逻辑。
- 通过现有 i18n 字典提供新增 UI 文案，保持多语言首轮 SSR 与 hydration 树一致。

## 技术设计

### 模板集合

详情页在 `sections`/`mapGroups` 形成后，为每个实际渲染的地图卡片生成唯一模板 URL，并去重。图片 URL 继续使用绝对 `/data/img/*.webp` 路径。识图组件开启后，先预加载这些 URL；掉落详情页保留默认 `IntersectionObserver` 占位行为，开启识图时通过独立预加载通道获取全部模板，不强制改变页面滚动性能。

### 识别流程

1. 从粘贴事件的 `clipboardData.items` 读取 `image/*` Blob，拒绝非图片内容。
2. 将截图和模板解码到 Canvas，按截图尺寸与模板尺寸计算多个缩放比例。
3. OpenCV.js 对每个模板的 `0/90/180/270°` 旋转候选执行灰度化、多尺度 `matchTemplate` 和阈值筛选；保留置信度最高的非重复矩形。
4. 多尺度结果不足时，对截图与模板执行 ORB、描述子匹配和单应性/边界估计，过滤低质量和越界结果。
5. 对重叠结果做非极大值抑制，按模板名称保留可解释的边界。
6. 在输出 Canvas 复制截图，仅对结果矩形填充 `rgba(0, 190, 80, 0.5)`，不绘制模板图片或文本。

### 兼容与失败处理

- OpenCV.js 动态加载或识别失败时展示明确错误状态，不阻塞详情页其它内容。
- 识图组件只在客户端交互后出现；服务端仅渲染关闭的开关和空状态，避免访问 `window`、`navigator.clipboard` 或 Canvas API。
- 截图过大时按最长边限制内部计算尺寸，导出仍使用原始截图尺寸和比例映射。

## 验收标准

- 关闭开关时不加载 OpenCV.js，不读取截图，不增加地图图片请求。
- 开启后指定区域可通过 `Ctrl+V` 读取截图，并显示模板加载/识别状态。
- 当前页面所有地图模块模板都参与识别，包括掉落页尚未进入视口的模块。
- 成功识别的区域为 50% 透明绿色覆盖，原 WebP 不出现在截图结果上。
- 可在浏览器下载标注后的图片；识别和导出不产生网络上传请求。
- 十语言页面无 hydration 错误，SSG 构建和 HTTP 200 验证通过。
