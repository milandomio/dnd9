# 游戏内地图识别优化

## 目标

在已完成的本地截图识图功能上降低完整截图识别耗时，并允许用户按截图质量调整识别召回率。所有处理继续在浏览器本地完成，不上传截图，不改变 SSG、SEO 和静态部署架构。

## 当前基线

- 初版对每张完整截图执行“页面模板数 × 4 个旋转 × 8 个尺度”的全屏模板匹配。
- `/zh-Hans/lootdrops/GoldenKey/` 使用 `test-cap.png`（废墟 2 层/地穴）时，11 个模板识别到 5 个模块，耗时约 51 秒。
- `test-cap1.png` 的 `TreasureRoom_01` 裁剪图旋转 `0/90/180/270°` 均识别成功，单次约 0.7 秒。

## 已完成优化

1. [x] 自动定位高亮的大地图面板 ROI，将精匹配范围从完整 `800x450` 工作图缩小到约 `330x320`。
2. [x] 将 ROI 内坐标偏移映射回原始截图，导出仍保持 `1920x1080`。
3. [x] 根据 ROI 占截图比例和匹配模块尺寸识别 `5x5/7x7` 网格；证据不足时不猜测。
4. [x] 已知网格只检查相邻 3 个模板尺度；无法判断网格或裁剪图继续使用完整尺度列表。
5. [x] ORB 场景特征只计算一次，所有未命中模板共享描述子。
6. [x] 模板超过 18 张时先在半尺寸 ROI 粗筛，再对最高 18 个候选做精匹配。
7. [x] 增加地图分组选择器；选项实时来自当前页面经过现有过滤后仍显示的地图分组，默认选择“全部”，失效选项自动回退“全部”。

## 待实施

2. [ ] 增加“识别精度”下拉预设：标准、高召回、极高召回、自定义。
3. [ ] 提供 `0.20-0.90` 数值输入；用户手动修改后自动切换到自定义。
4. [ ] 阈值变化时不重新加载 OpenCV 和模板，只影响下一次粘贴识别。
5. [ ] 使用炼狱 5 个真值模块校准预设：高召回目标至少 5/5，同时记录误报数量。
6. [ ] 复测地穴、7x7、四方向裁剪图，防止降低阈值破坏边界去重和旋转识别。

## 精度参数设计

| 预设 | 初始阈值 | 目标 |
|------|----------|------|
| 标准 | `0.52` | 优先抑制误报，保持当前行为 |
| 高召回 | `0.45` | 识别压缩、遮挡和轻微尺寸误差 |
| 极高召回 | `0.38` | 尽量找全目标，允许更多误报 |
| 自定义 | 用户输入 | 用于特定截图、UI 缩放和后续校准 |

阈值越低，识别成功率和误报率都会上升。结果仍经过局部峰值筛选、同模板非极大值抑制和跨模板重叠去重，不直接绘制所有低分候选。
