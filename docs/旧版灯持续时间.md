- **数据来源**：`data/json/lights.json`（游戏 0.18.156 更新前，火把燃烧时间为 60~180 秒的那一版）
- **导出日期**：2026-10-16

- **字段**：燃烧时间 = `FuelSeconds`；照明范围 = `LightAreaRadius`
